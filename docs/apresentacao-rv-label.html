1 · Modelagem de Dados

O banco guarda os dados com regras

  • Modelo lógico no MySQL Workbench e schema.sql com 13 tabelas ligadas por chaves.
  • Chave composta: a variação é produto + cor + tamanho, e o estoque fica nela.
  • CHECK no banco: preço ≥ 0, quantidade > 0, subtotal = quantidade × preço.
  • Views bi_* entregam valor líquido, custo e lucro prontos para o BI.

Transação: o pedido é tudo ou nada

  1. 1
    Trava o estoque da peça FOR UPDATE
  2. 2
    Confere a quantidade e desconta UPDATE
  3. 3
    Grava o pedido e os itens INSERT
  4. 4
    Confirma tudo COMMIT

Se qualquer passo falhar, ROLLBACK desfaz tudo e o estoque não fica errado.

2 · Lógica de Programação

O código faz as contas

  • Indicadores: soma com for, maior e menor com while, média = soma ÷ quantidade.
  • Vitrine: filtro com && (tamanho, cor, preço); sem preço vai para o fim.
  • Em lote: continue pula quem já está pronto; try/catch guarda os erros sem parar.
lib/core/indicadores_vendas.dart
if (vendas.isEmpty) return null; // sem dividir por zero
double soma = 0;
for (final v in vendas) { soma += v; }
int i = 1;
while (i < vendas.length) {
  if (vendas[i] > maior) maior = vendas[i];
  if (vendas[i] < menor) menor = vendas[i];
  i++;
}
3 · Programação Orientada a Objetos

As classes barram valores errados

  • Abstração: Produto é abstrata; só existe Peca ou Acessorio.
  • Encapsulamento: _nome e _preco são privados e o setter valida.
  • Polimorfismo: peça responde P, M, G; acessório responde “Único” com override.
  • Ocultação: a sacola guarda os itens num mapa privado.
lib/models/produto.dart
abstract class Produto with Serializavel {
  String _nome;
  double? _preco; // null = "Preço a definir"

  String get nome => _nome;
  set nome(String valor) => _nome = _validarNome(valor);
  set preco(double? valor) => _preco = _validarPreco(valor);
}
// preço negativo → ArgumentError
4 · Business Intelligence

O dashboard vira informação

  • Power Query corrige tipos, tira duplicatas e cria região, faixa de preço e segmento.
  • Modelo estrela: 3 fatos (vendas, estoque, metas) e 5 dimensões.
  • DAX: Faturamento, Ticket médio, Margem, Meta, Curva ABC, em 6 páginas.
