RV

Fluxo de dados do dashboard de vendas

Do pedido feito no app ou no site até o dashboard publicado no Power BI Service

1Origem dos dados

App Flutter · site React · API Node.js
  • Clientes fazem pedidos pelo app e pelo site
  • A API grava pedidos, itens, clientes, catálogo e estoque
  • No painel, a loja informa custo das peças, metas e o status do pedido (Entregue)
Demonstração2.257 pedidos simulados (ago/2024 a out/2026), marcados com simulado = 1

2Banco MySQL

MySQL 8 · banco rv_label
  • 14 tabelas: pedido, item_pedido, produto, cliente, categoria, vendedor, meta_mensal, estoque_mensal…
  • 8 views bi_* já no formato do modelo (vendas, estoque, metas, produtos, categorias, clientes, vendedores, calendário)
  • Usuário powerbi_leitura: só SELECT nas views, sem CPF, telefone ou endereço
Scriptrv_label_banco_mysql.sql

3Conexão

MySQL Connector/NET · modo Importação
  • Conector MySQL do Power BI lê as 8 views
  • Parâmetros Servidor (localhost) e Banco (rv_label): trocar para o banco hospedado sem mexer nas consultas
  • Senha guardada no Windows, nunca dentro do arquivo

4Tratamento no Power Query

Linguagem M · 8 consultas
  • Tipos de dados (data, texto, decimal)
  • Limpeza: espaços e caracteres invisíveis, UF vazia vira "NI", duplicatas removidas
  • Função fxNomeProprio padroniza nomes
  • Colunas novas: Região, Primeiro nome, Segmento (mescla com as vendas) e Local para o mapa

5Modelagem

Esquema estrela
  • 3 fatos: Vendas, Estoque, Metas
  • 5 dimensões: Calendário, Produtos, Categorias, Clientes, Vendedores
  • Relações 1:N de cada dimensão para os fatos
  • Hierarquias Calendário (Ano › Trimestre › Mês) e Geografia (Região › UF › Cidade)

6Indicadores DAX

37 medidas
  • Vendas: Faturamento, Lucro, Margem %, Ticket médio, Descontos
  • Metas: Meta, Atingimento %
  • Produtos: Curva ABC (% acumulado, classe)
  • Clientes: novas x recorrentes, % recompra, clientes a reativar
  • Estoque: valor em estoque, SKUs em atenção, situação

7Dashboard

Power BI Desktop → Power BI Service
  • Template no PowerPoint, exportado em PNG como fundo das 6 páginas
  • Segmentações de mês e categoria e botões de navegação
  • Drill-down nas hierarquias e mapa de faturamento por cidade
  • Cartões de KPI, gráficos, tabelas e matriz
PublicaçãoPower BI Service: link do relatório e atualização agendada
Atualização Ao clicar em Atualizar (ou na atualização agendada do Service, via gateway), o Power BI relê as views do MySQL, refaz os passos do Power Query, recalcula as medidas e redesenha os visuais. Nenhuma etapa é feita à mão.
